# 🎭 AI Mafia

Нейросети играют в «Мафию» друг с другом: сидят за столом в таверне, спорят, подозревают, голосуют, а ты смотришь и слушаешь. Каждый игрок говорит своим голосом и ходит через API своей модели.

Чистый front-end: HTML, CSS и JavaScript, без сервера и сборки. Ключи API хранятся только в твоём браузере.

## Возможности

- **Разные нейросети за одним столом.** У каждого игрока свой провайдер и модель: GPT, Claude, Gemini, DeepSeek, Grok, Llama, Mistral, Qwen и любые другие через OpenRouter или свой OpenAI-совместимый адрес.
- **Озвучка.** OpenAI TTS, ElevenLabs, Gemini TTS (30 голосов) или бесплатные голоса браузера. Голос подбирается под бренд нейросети и не повторяется за столом. Реплика озвучивается вместе с появлением текста.
- **Стиль стрима.** Таверна, табло раунда, шарики в шляпах цвета своей нейросети, облачко над говорящим. Говорящий подпрыгивает, светится и открывает рот.
- **Полная игра.** Знакомство, ночь, день с обсуждением, голосование. Роли: мафия, комиссар, доктор, мирные жители.
- **Ночь вслух.** Мафия обсуждает, кого убрать и почему. Доктор и комиссар тоже объясняют свой выбор. Зритель слышит всё, игроки друг про друга ничего не знают.
- **Имена и аватарки по модели.** Игрок называется как его нейросеть (ChatGPT, Claude, Gemini…), а внешний вид выбирается по бренду. Вручную можно поменять всё.
- **Демо-режим.** Игрок без ключа своего провайдера говорит заготовленными фразами, так что поиграть можно и без единого ключа.

## Быстрый старт

1. Скачай репозиторий и запусти локальный сервер в его папке:

   ```bash
   npx http-server -p 8080
   ```

2. Открой http://localhost:8080.
3. Нажми «⚙ Настройки» и вставь ключи тех провайдеров, которыми хочешь играть.
4. Выбери каждому игроку провайдера и модель, затем «Сохранить».
5. Нажми «▶ Начать игру».

Открывать `index.html` двойным кликом тоже можно, но через сервер надёжнее.

## Провайдеры

| Провайдер | Модели по умолчанию | Примечание |
|---|---|---|
| OpenAI | `gpt-4o-mini` и другие GPT | Ключ также нужен для OpenAI TTS |
| Anthropic | `claude-haiku-5-5` и другие Claude | Родной Messages API |
| Google Gemini | `gemini-2.5-flash` и другие | Ключ также нужен для Gemini TTS |
| DeepSeek | `deepseek-chat` | Режим рассуждений отключён для экономии |
| xAI | `grok-3-mini` | |
| Deploy | DeepSeek, GLM | https://docs.deploy.com |
| OpenRouter | любая модель каталога | Самый простой способ получить Llama, Mistral, Qwen и другие |
| Свой | любой OpenAI-совместимый адрес | Укажи базовый URL в настройках |

Если провайдер блокирует запросы из браузера (ошибка CORS), используй OpenRouter: через него доступны все модели.

## Настройки

- **Ключи API:** отдельный ключ для каждого провайдера.
- **Озвучка:** движок, модель, скорость, голос каждого игрока. Для ElevenLabs можно подгрузить свои голоса кнопкой.
- **Игра:** количество кругов обсуждения, язык, показ ролей (режим зрителя).
- **Аватарки:** шарики в шляпах, арт-мафиози, логотипы или свои эмодзи и картинки.
- **Игроки:** имя, провайдер, модель, голос, характер.

Настройки и ключи лежат в `localStorage` браузера и уходят только своему провайдеру.

## Если что-то не работает

- **Игроки говорят заготовленными фразами.** Для их провайдера не сохранён ключ. Проверь настройки и нажми «Сохранить».
- **Ошибка 400 или 401 от провайдера.** Проверь ключ и название модели. Игра сама повторит запрос без параметров рассуждения, если модель их не принимает.
- **Ошибка CORS.** Провайдер не разрешает запросы из браузера. Используй OpenRouter.
- **Нет звука.** Проверь движок озвучки и ключ к нему. Браузерные голоса работают без ключа.
- **Игра «зависла».** Запрос к модели ограничен по времени и повторяется. Статус виден под столом.
