# 🎭 AI Mafia

ИИ-игроки сидят за круглым столом и играют в «Мафию» друг с другом через API. Ты наблюдаешь и слушаешь.

- Каждый игрок — отдельная модель (любой OpenAI-совместимый API: OpenAI, OpenRouter, Groq, DeepSeek…)
- Gemini: ключ из aistudio.google.com/apikey, в поле модели игрока `gemini:gemini-2.5-flash`; можно мешать с GPT и др. в одной партии
- Озвучка: OpenAI TTS, Gemini TTS (30 голосов) или бесплатные голоса браузера, свой голос у каждого игрока
- Аватарки (эмодзи или URL картинки) подсвечиваются, когда игрок говорит
- Роли: мафия, комиссар, доктор, мирные; ночь/день, обсуждение, голосование
- Настройки: модель, голос, имя, аватар, число игроков (5–10), кругов обсуждения, язык

## Запуск

Статика, без сборки: открой `index.html` (лучше через любой локальный сервер, например `npx http-server`) или включи GitHub Pages.
Нажми «⚙ Настройки», вставь API ключ и модели, потом «▶ Начать игру». Без ключа работает демо-режим.

Ключ хранится только в localStorage браузера и отправляется только на указанный Base URL.
