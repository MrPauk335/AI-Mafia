# 🎭 AI Mafia

ИИ-игроки сидят за круглым столом и играют в «Мафию» друг с другом через API. Ты наблюдаешь и слушаешь.

- **У каждого провайдера свой ключ:** OpenAI (GPT), Anthropic (Claude), Google (Gemini), DeepSeek, xAI (Grok), OpenRouter, свой OpenAI-совместимый
- **У каждого игрока свой провайдер и модель** (или «Авто» — игроки по очереди делят провайдеров, у которых есть ключ)
- Игрок без ключа своего провайдера говорит заготовленными фразами (демо)
- Озвучка: OpenAI TTS, Gemini TTS (30 голосов) или бесплатные голоса браузера; свой голос у каждого игрока
- Аватарка подбирается по модели (GPT, Claude, Gemini, DeepSeek, Grok, Llama, Mistral, Qwen + нарисованные для Kimi, GLM, Perplexity, Cohere, Microsoft, NVIDIA, Amazon, MiniMax); подсвечивается, когда игрок говорит
- Игра: знакомство, ночь, день, обсуждение, голосование. Роли: мафия, комиссар, доктор, мирные
- Ночью мафия вслух обсуждает, кого убрать и почему; доктор и комиссар тоже говорят выбор с причиной (зритель всё слышит)

## Запуск

Статика, без сборки: открой `index.html` (лучше через локальный сервер, например `npx http-server`).
«⚙ Настройки» → вставь ключи нужных провайдеров → выбери провайдера и модель каждому игроку → «Сохранить» → «▶ Начать игру».

Ключи хранятся только в localStorage браузера и отправляются только своему провайдеру.
Если провайдер блокирует запросы из браузера (CORS), используй OpenRouter — через него доступны все модели.
